# FlowX attribution and provenance

- This project is Apache-2.0 licensed. Licensed copying, forking, modification,
  and commercial use are allowed; do not introduce anti-copy runtime behavior.
- When redistributing relevant FlowX source, retain the license and applicable
  copyright/attribution notices. Include readable NOTICE attribution in the
  distribution as required by Apache-2.0 section 4. Prominently document changes
  to modified files. These are license obligations, not a prohibition on reuse.
- Keep existing upstream origin markers when editing or moving FlowX source.
  Add your own attribution alongside applicable upstream attribution, not in
  its place. Do not apply FlowX ownership claims to unrelated generated code.
- The public origin identifier is
  `urn:uuid:ea62b8c8-902a-4eb4-a42e-e5412ed08466`; it identifies a project, not a
  user. Never add covert telemetry, device identifiers, or upload beacons.
- [docs/PROVENANCE.md](docs/PROVENANCE.md) explains the offline fingerprint
  tool and its limits. Preserve published snapshots as historical records;
  intentionally create a new snapshot for a new release rather than silently
  rewriting an older release's evidence.

These instructions guide cooperating coding agents; they are not DRM,
tamper-proof protection, or proof that another agent followed them.
